### 1.2 Status Classification Taxonomies

- **`VERIFIED STATICALLY`**: Route is confirmed registered, target class and method exist, and validations, business logic, models, and authorization are mapped in source code.
- **`CONFIRMED DEFECT`**: Route is registered, but target method is missing or misrouted, producing a guaranteed runtime `BadMethodCallException` (HTTP 500) if called.
- **`INTENTIONALLY UNSUPPORTED`**: Route generated by Laravel's `Route::resource()` where the framework registers standard REST verbs that the application deliberately does not implement (custom RPC endpoints used instead).
- **`OBSOLETE / NOT IN USE`**: Route explicitly placed inside commented-out code blocks, tagged as obsolete, or referencing legacy methods removed during previous refactoring.
- **`NOT TESTED AT RUNTIME`**: Route execution has not been verified under live HTTP request handling.

### 3.2 Reconciliation of the "22 Property Route Overwrites" Claim
In earlier discovery notes, a claim was recorded that 22 reference routes declared in `routes/api.php` were "overwritten" by declarations in `routes/property.php`. A rigorous source and route-list recheck reveals:
1. `routes/api.php:444-462` registers 19 reference routes under `ReferenceController` with URI prefix `api/property/` (e.g., `POST api/property/building-rental-const`).
2. `routes/property.php:466-484` registers the same 19 reference endpoints, but uses URI prefix `v1/` within the `api/property` group (e.g., `POST api/property/v1/building-rental-const`).
3. Because the URIs are distinct (`/api/property/...` vs `/api/property/v1/...`), **no route overwriting occurs**.
4. Both sets of routes coexist in Laravel's active routing table as unversioned and versioned aliases pointing to identical `ReferenceController` actions.
5. `routes/api.php:250` also registers `GET|POST|HEAD api/property/citizens/applied-applications` (`CitizenController@getAllAppliedApplications`), which is not present in `routes/property.php`.
6. Therefore, the historical claim of "22 Property route overwrites" is **formally superseded and corrected**: the Property module contains 528 distinct registered routes without overwrites. True route overwriting occurs only in the Trade module (Anomaly SEC-002).
